# OgibArm

OgibArm — бесплатная программа для формирования огибающих армирования по DXF-результатам ЛИРА-САПР.

[Официальная страница](https://water-faq.github.io/OgibArm/) · [Скачать актуальную версию](https://github.com/Water-FAQ/OgibArm/releases/latest/download/OgibArm_1.0.1.zip) · [Все выпуски](https://github.com/Water-FAQ/OgibArm/releases)

## Что нового в версии 1.0.1

- исправлено отображение русских имён встроенных тестовых DXF;
- для тестов R12 и R2007 автоматически выбираются шкалы «Фон s200d12» и «Фон s200d8»;
- прозрачный фон PNG выбран по умолчанию;
- обновлены тестовые комплекты и проверка их состава перед загрузкой;
- добавлены автоматическая проверка обновлений и безопасная установка с проверкой размера, SHA-256 и состава архива;
- обновление откладывается до завершения обработки, а при ошибке предыдущая версия восстанавливается;
- повторный запуск выводит работающую программу на передний план и не создаёт вторую копию;
- дополнены встроенная справка и сведения в свойствах EXE.

## Возможности

- объединение нескольких результатов подбора армирования в отдельные огибающие NX, NY, VX и VY;
- поддержка типов DXF R12 из ЛИРА-САПР 2021 и R2007 из ЛИРА-САПР 2024;
- автоматическое распознавание направления по имени файла и ручное назначение;
- исходная КЭ-сетка или регулярная условная сетка заданного размера;
- полилинии, штриховки и объекты `3DFACE` в итоговых DXF;
- дополнительный экспорт PNG с разрешением до 8192 пикселей;
- общая или отдельные шкалы верхнего и нижнего армирования;
- пользовательские ступени и импорт шкал ЛИРА-САПР из `.shk`;
- именованные конфигурации;
- встроенные тестовые комплекты R12 и R2007;
- светлая и тёмная темы;
- подробный журнал и безопасная остановка обработки;
- портативная работа без установки.

## Начало работы

1. [Скачайте последнюю версию](https://github.com/Water-FAQ/OgibArm/releases/latest/download/OgibArm_1.0.1.zip).
2. Распакуйте архив в удобную папку.
3. Запустите `OgibArm.exe`.
4. Добавьте DXF, проверьте направления, настройте результат и нажмите «Сформировать огибающие».

## Совместимость

OgibArm предназначен для 64-разрядных Windows 10 и Windows 11.

В пределах одного направления все исходные файлы должны иметь один тип DXF. Разные направления в одном запуске могут обрабатываться в разных типах DXF.

## Проверка сборки

SHA-256:

- `OgibArm_1.0.1.zip`: `b1bdd92a56491582732269ed1afd1d9f292b4463b1033bdf8529d5fec7541581`
- `OgibArm.exe`: `42b36ef39f3f37c90758167eeafba85294491b69f5183999cd3cfe2f09d33ce8`

OgibArm не имеет цифровой подписи, поэтому Windows и некоторые антивирусы могут предупреждать о запуске неизвестного приложения.
