# OgibArm

**Огибающие армирования из DXF ЛИРА-САПР без ручного сведения файлов.**

Когда результаты подбора армирования выгружены по нескольким сочетаниям или расчётным случаям,
их приходится сопоставлять и собирать в общую картину. OgibArm берёт эту рутинную часть на себя:
объединяет DXF одного направления, выбирает максимальное требуемое армирование и формирует готовую
огибающую для дальнейшей проверки и работы в CAD.

Программа обрабатывает до четырёх направлений — `NX`, `NY`, `VX` и `VY`. Для каждого фактически
загруженного направления создаётся отдельный итоговый DXF, а при необходимости — ещё и PNG.

> Текущая версия: **OgibArm 1.0.0**  
> Платформа: **Windows 10/11 x64**

[**Скачать последнюю версию OgibArm**](https://github.com/Water-FAQ/OgibArm/releases/latest/download/OgibArm.zip)

Другие версии и описание изменений находятся в разделе
[Releases](https://github.com/Water-FAQ/OgibArm/releases).

## Что умеет OgibArm

- объединяет несколько DXF в одну огибающую отдельно для каждого направления армирования;
- поддерживает типы DXF `R12` и `R2007` из разных поколений ЛИРА-САПР;
- сохраняет исходную КЭ-сетку или строит результат по заданной условной сетке;
- создаёт полилинии, штриховки и объекты `3DFACE` в нужном сочетании;
- формирует PNG размером 2048, 4096 или 8192 пикселей с белым либо прозрачным фоном;
- позволяет использовать общую или раздельные шкалы для верхнего и нижнего армирования;
- загружает шкалы ЛИРА-САПР из файлов `.shk`;
- сохраняет именованные конфигурации обработки;
- ведёт подробный журнал с этапами, предупреждениями, ошибками и временем выполнения;
- работает в светлой и тёмной темах;
- содержит встроенную справку и отдельные тестовые наборы R12 и R2007.

В итоговый DXF попадают только действительно использованные ступени армирования. Пустые слои и
отсутствующие ступени в легенду не добавляются.

## Поддерживаемые типы DXF

| Тип DXF | Типичный источник | Как читается армирование |
|---|---|---|
| `R12` | ЛИРА-САПР 2021 | По цветовым ступеням ACI и данным блока `KLEENKA` |
| `R2007` | ЛИРА-САПР 2024 | По точным числовым значениям из слоёв результатов |

Внутри одного направления все исходные файлы должны иметь одинаковый тип DXF: только R12 или
только R2007. Если в одном направлении оказались файлы разных типов, OgibArm сообщит об ошибке и
остановит обработку до формирования результатов. При этом разные направления могут использовать
разные типы DXF.

Для R2007 числовые значения консервативно переводятся в выбранную пользователем шкалу: программа
назначает первую ступень, которая полностью покрывает требуемое армирование.

## Как начать работу

1. Скачайте `OgibArm.zip` по ссылке выше и распакуйте архив в удобную папку.
2. Запустите `OgibArm.exe` — установка не требуется.
3. Добавьте DXF кнопкой, целой папкой или перетащите файлы из Проводника.
4. Проверьте направления `NX`, `NY`, `VX`, `VY`. Они определяются по началу имени файла, но их
   можно изменить вручную.
5. Выберите шкалу армирования, основу построения и состав результата.
6. Нажмите **«Сформировать огибающие»**.

Оригинальные DXF не изменяются. Перед обработкой OgibArm создаёт рабочие копии и выполняет все
операции только с ними.

## Тестовые наборы

Познакомиться с программой можно без подготовки собственных файлов. Откройте
**«Настройки» → «Шкалы и тест»** и выберите один из наборов:

- **R12 (ЛИРА-САПР 2021)**;
- **R2007 (ЛИРА-САПР 2024)**.

Файлы выбранного типа будут добавлены в главное окно с назначенными направлениями. Формирование
огибающих не запускается автоматически — параметры можно спокойно изучить и изменить.

## Важно

OgibArm автоматизирует обработку DXF, но не выполняет расчёт строительных конструкций и не
проверяет физический смысл результатов подбора армирования. Перед использованием в проектной
документации необходимо сопоставить исходные данные, параметры обработки и полученный результат.

Обработка выполняется локально. Исходные DXF и сформированные результаты не передаются через
интернет. Сетевое подключение используется только для проверки наличия новой версии, если эта
функция включена пользователем.

Программа распространяется бесплатно. Разрешается использовать и распространять оригинальную
неизменённую версию OgibArm при сохранении названия, сведений о разработчике и условий
использования. Продажа программы и публикация изменённых версий под названием OgibArm без
согласования с разработчиком не допускаются.
