# Безопасность OgibArm

Если вы обнаружили возможную уязвимость OgibArm или официального сайта, пожалуйста, не публикуйте технические подробности в открытом обращении.

Сообщите о проблеме по электронной почте: [waterfaq@ya.ru](mailto:waterfaq@ya.ru).

Укажите версию OgibArm, версию Windows, краткое описание проблемы и безопасные шаги для её воспроизведения. Не прикладывайте пароли, ключи, персональные данные, рабочие DXF и другие конфиденциальные сведения.

Обычные ошибки обработки и предложения новых возможностей можно отправлять через [GitHub Issues](https://github.com/Water-FAQ/OgibArm/issues).
